# FocusDrop

One task. One timer. A clean focus log.

FocusDrop is a minimal, dependency-free focus timer. You name what you're
working on, run a 25-minute focus session, and every session — completed,
finished early, or dropped — is logged locally in your browser. A daily
summary shows completed sessions and total focused minutes.

## Why

Deep work works best when the unit of work is small and obvious. FocusDrop does
one thing end to end: turn an intention into a tracked focus session. No
accounts, no backend, nothing else to learn.

## Features

- Name a task, start a 25-minute timer
- Completed sessions are auto-logged with today's totals
- Finish early logs partial minutes; dropping a session logs nothing
- Optional on-page scope plan (`plan.md`) — plan before build, per the
  Devpost Learn Skill Pack habit
- History persists in `localStorage` across refreshes
- Single HTML file, zero dependencies, runs in any modern browser

## How to run

Open `index.html` in any browser. That's it.

## Tech

HTML, CSS, vanilla JavaScript, localStorage.
